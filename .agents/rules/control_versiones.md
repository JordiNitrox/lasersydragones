# Regla de Control de Versiones (Git)

> 🚨 **REGLA MANDATORIA DE GIT PARA EL PROYECTO:**
> **PROHIBIDO hacer `git commit` o `git push` de forma autónoma o automática.**
>
> 1. Toda acción de control de versiones (`git commit`, `git push`) debe ser requerida **única y exclusivamente mediante orden explícita y directa del usuario** (ej. *"haz commit y push"*).
> 2. Durante la ejecución de cualquier tarea (redacción de capítulos, corrección de incoherencias, edición de glosarios, maquetación o compilación de PDFs), los cambios deben permanecer únicamente en el árbol de trabajo local (*working directory*) sin confirmarse en Git ni subirse al repositorio remoto hasta recibir instrucción expresa.
